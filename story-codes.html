Every finished life in Soft Life: Abuja ends as a Story Code, a short string a player can copy and share by hand. Paste a code below and this page reads the life it carries: the path lived, the ending reached, and the mark the life left on the city. The reading happens in your browser. What a Story Code is

Finish a run in Soft Life: Abuja and the game mints your Story Code. The code holds the shape of that one life: the life path you lived, the ending you reached, the chapter the run reached, your Soft Life Index, the number of famous rulings you filed, every ending gathered across your Story Log, and the flavour of your family ledger. That flavour travels as two broad bands, Generosity and Boundaries, never as the private numbers behind them.

Codes travel by hand. A player copies the code and sends it however they like: a chat message, a note, a post. The game itself sends nothing. There is no network, no server, and no account anywhere in the design, and this page keeps the same law. It decodes locally, in the browser, and forgets the code the moment you leave.

The code ends in a checksum, and we describe it honestly: it catches typing slips and casual changes, so a copied code either reads clean or refuses. It is a copy check, not a lock. The format is published, anyone can study it, and nothing in the game or on this page trusts a code for more than the story it tells.

What a code never carries

No names. No messages. No free text of any kind. A code is built only from fixed vocabularies the game itself defines: ending names, chapter numbers, counts, and bands. It also carries no money, no items, and no progress. Reading a friend’s life gives you their story. It never gives you anything they earned.

Life Swap, arriving with version 1.1

In the game today, entering a friend’s code already opens a comparison of your two Abuja lives side by side, files one rivalry beat in your Story Log, and sets their Soft Life Index as the ghost target in Endless Abuja.

The next step is in development for the version 1.1 update, the update that brings the city itself to life. Life Swap seats a friend’s finished household inside your own Abuja: a family that lived the life their code describes, living at an address in your city, there to be visited. Their story arrives in your game. Nothing else does: no money moves, no items change hands, and your own run is untouched.

The design reaches further. Soft Life is a series, and the same codes are being built to travel between its cities, so a life finished in Abuja can one day emigrate to a later edition and take its place in a new city, the way lives actually move. When that ships, this page will read those codes too.
